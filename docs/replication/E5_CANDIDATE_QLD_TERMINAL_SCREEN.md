# E5 candidate screen: Queensland Wet Tropics

Status: **E5_CANDIDATE_NOT_QUALIFIED**

The Queensland design remained the strongest named E5 candidate for several response-blind
steps. Public metadata showed matched road/bush camera sampling, repeated-visit methodology,
146 coordinate pairs and seven calendar months across the transformed VerbatimEvent material.

The decisive problem appears only when the frozen E5 requirement is applied at the required
**Deployment** grain.

The one-shot completeness diagnostic scanned 271 Deployment rows. All 271 have an empty
`eventDate`; all 271 also have an empty `samplingProtocol`. Therefore there are
**0 response-independent complete-case deployments** from which deployment effort intervals
can be reconstructed.

E5 requires deployment/site effort intervals before focal response opening. Reconstructing
camera effort from first/last trigger or detection events would make effort depend on the
response and is therefore forbidden.

Consequently:

- G1 independent source: PASS

- G3 crossed domain: not adjudicated after the G2 hard stop
- G4 detection identifiability: not adjudicated after the G2 hard stop
- G5 physical replication: substantial public spatial capacity exists, but no qualifying
  complete-case deployment set can be formed

No biological response, species/taxon values, occurrence rows, multimedia rows, or focal
outcomes were opened. This is a metadata qualification stop, not a biological negative
