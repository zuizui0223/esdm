# E6 SNAPSHOT USA: anonymous Dryad download blocked (not a biological result)

**2026-10-19 independent-data transport finding:** the public dataset pages, official version metadata and the SHA256 file manifests are accessible without logging in, but the official **file-body** API requires authentication. The exact [metadata-only GitHub run 39213249450](https://github.com/zuizui0223/esdm/actions/runs/39213249450) executed **4 synthetic response-blind tests successfully**, then received **HTTP 401** from:

`https://datadryad.org/api/v2/files/4016828/download`

Therefore the first 2019–2023 deployment table was not downloaded, the 2024 table was not processed, and **zero biological sequence rows were opened**. This is the outcome **`RESPONSE_UNOPENED_TRANSPORT_STOP_AUTH_REQUIRED`**, NOT an ecological negative or confirmation.

The frozen public original file IDs, dataset versions and SHA256 values are preserved in the accompanying [machine-readable receipt](E6_SNAPSHOT_DRYAD_TRANSPORT_STOP.json) and [pre-outcome hypothesis/design](E6_SNAPSHOT_URBAN_TEMPORAL_ASSEMBLY_FROZEN_DESIGN.md).

Dryad's [official API account documentation](https://github.com/datadryad/dryad-app/blob/main/documentation/apis/api_accounts.md) states that downloading files requires a bearer token. If authenticated, trusted Dryad-origin bytes with their pinned SHA256 can later be supplied to the already-written E6 script. No personal login or secrets should be embedded into GitHub, a chat, an issue, or source code. Do not retry the same anonymous API endpoint as though it were a model-qualification gate; no method threshold has changed.
