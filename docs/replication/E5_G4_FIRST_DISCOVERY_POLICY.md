# E5 G4-first discovery policy

After 14 response-blind candidate screens, the search bottleneck is no longer generic
data availability. The scarce design property is the joint presence of:

1. a detection channel that is identifiable separately from activity; and
2. overlap of that detection/source/protocol factor across geographic regimes.

Future discovery therefore starts with G4 and G3, not sample size.

A candidate enters detailed qualification only if public methods/schema/metadata show
one of: retained paired-camera/double-observer member identity, deployment-linked
distance calibration, an auxiliary detection stream tied to the same deployments, or
another predeclared response-independent detection-identification mechanism.

The same factor must occur in at least two geographic regimes. Paired cameras in the
field are insufficient if released data collapse the two members; multiple camera models
are insufficient without overlap/calibration.

Only after these conditions pass are effort reconstruction, six-month temporal support,
20/10 physical-location counts, model freeze, and focal-response opening considered.

No E5 gate is changed by this policy. It only changes search order.
