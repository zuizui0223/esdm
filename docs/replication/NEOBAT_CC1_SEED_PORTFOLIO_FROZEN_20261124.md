# Prospective CC1 seed-rain × NeoBat candidate portfolio

Frozen 2026-11-24 before reading full numerical seed series. This is a **different** single-site resource diagnostic from BCI (PR #280); it is not a replacement dataset selected after inspecting BCI performance.

- Field series: Pak et al. (2023), *Multiscale phenological niches of seed fall in diverse Amazonian plant communities* (Ecology, DOI 10.1002/ecy.4022); authors' processed Cocha Cashu site time-series CSV `treephenecology_2023/DryadData/CC1_ALL_FINAL.csv` at GitHub repository `pakdamie/TreePhenEcology`, immutable commit `521b118b75af4d1bb2b7feadb28b077a09301eab`, Git blob SHA `dc95badb04365449e9ad5a13e8a37c5a9fc552e9`. Published compiled seed-rain counts at approximately fortnightly sample events. This is **not** raw identified fruit biomass, not direct bat feeding, not satellite photos.
- Source network: `gflorezm/NeoBat_Interactions`, immutable original commit `d25292d19be32a85a21c60384a3f2d818e8081de`, `Data/NeoBat_Interactions_Records.csv`, SHA-256 `723198f850aa4ee7346122e71a3dd3eadaca176a65bfb87dc2a90f55f2acf10b`, exactly 2,571 interactions, with immutable original 26 primary frugivore candidates. Use `Interaction=Frugivory`, `TrophicGuild=Frugivore`, current bat/plant species names only.
- Frozen plant list: `docs/replication/NEOBAT_INDEPENDENT_PLOT_CROSSWALK_INPUT_20261121.json` 106 original species (SHA-256 `41c9fc0128df6d0f3753edf4b82f6b5b36c6975c8d7c644bae4e4fd3e5bdaac6`).

**Data parsing:** Full CC1 table, no rows selected by a measured result. First column is row index, `Group.1` observation date; last three astronomical fields `Day_Length,Day_Year,Day_Year_Y` excluded from plant counts. All other columns initially candidate species strings; only *exact* binomial forms `genus_species` matched to frozen 106 (casefold + replacing one underscore with space). No guessing on `cf.`, `sp.`, synonyms, or misspellings. Reject conflicting duplicate column names, duplicate dates, negative/nonfinite/invalid numeric counts; observed zero values remain **measured zeros**, missing cells remain **missing**, not zeros. The original table may contain later years; all published dates will be reported. No use of bat outcome information to tune portfolio.

**Exploratory analysis, fully determined before values:** For each bat among the fixed 26, retain all its NeoBat-recorded fruit-plant partners that exact-match a CC1 plant column and fixed 106 list. Include every bat in denominator. A temporal portfolio is descriptive only if at least **3 distinct plant species** and **60 shared numeric observation dates** remain (no value-dependent species filtering). For each plant calculate `log1p(seed_count)`, normalize by its across-shared-date arithmetic mean (must be positive), and average normalized transformed output equally across its partner species for each shared date. Statistic = across-date coefficient of variation of this mean. Compare with **499** fixed-seed `20261124` independently circular-shifted whole series preserving each species' time-series distribution/autocorrelation. Report ratio to the median null CV; below 1 is descriptively anti-synchronous/compensatory relative to the circular-shift null, above 1 synchronous. Null shift destroys shared seasonal alignment; **do not call it evidence beyond shared seasonality**. No p-values or cherry-picked threshold.
 
**Boundaries:** One Peru site; 26 candidate bat portfolio labels are not independent bats observed at Cocha Cashu. Source network links from other localities are not verified CC1 feeding interactions. Trap seeds are not ripe fruit abundance or edible fruit mass. Site-level analyses do not estimate global bat distribution or original M3−M1/N1. No bat response or predictive model fitted. Randomization is descriptive. Results may be null or ineligible. Preserve original file SHA and author source, field/date counts and all bat statuses, publish no raw site/sensitive coordinates.
