# NeoBat source-dataset-matched Colombia plant transfer pilot — post-hoc exploratory freeze

Date: 2026-11-19. Distinct fixed design after the original three-plant source-effort result was already opened. **Not a confirmatory retest** of a new ecological hypothesis and no bat M1/M3/N1 output.

The original pilot showed abiotic BIO1/BIO12/elevation-only AUCs 0.526/0.499/0.505 but high apparent combined AUCs entirely reconstructable using other-plant source-record count. A later original DOI audit showed that all 106×17 plant country-pairs have enough outcountry source data to construct pseudo-background **within shared GBIF datasetKey**; this is still not event or effort matching.

## Fix all changes to model and evaluation before outcome extraction

- Same source original plant DOI `10.15468/dl.xwc5zf`, 367,988 records and immutable original ZIP SHA; same 255 accepted plant species, 106 fixed v2 universe SHA, known <=12.5km source cells; same WorldClim 10 arcminute BIO1/BIO12 and elevation original ZIPs; no new GBIF POST.
- Same CO heldout country and **same three fixed sentinels**: `Cecropia obtusifolia`, `Ficus insipida`, `Piper aduncum`; retain all three and all stops, no replacement based on response or previous AUC.
- **New dataset-matched source selection only**: eligible positive focal cells in country have a nonempty `datasetKey` that also records at least one other plant taxon elsewhere within the same country; eligible pseudo-background cells record other taxa in one of these exact original `datasetKey` sources and contain no known focal plant record from any dataset.
- Both positive and background cells must also contain >=1 **other accepted plant taxon** in the same 25km cell (across the original 255 GBIF cohort). Define the source-observation intensity covariate `log1p(n_other_plant_taxa_in_cell)` as before. This restriction preserves the positive/background recording-context symmetry of the original three-species plant pilot; it can remove some otherwise source-qualified focal cells. All losses are counted.
- Never train on any CO plant record, and remove all CO source-observed cells from training even if an outcountry point shares the 25km cell. Training feature standardization uses outcountry cells only, fixed `LogisticRegression(C=1,class_weight='balanced',max_iter=400,solver='lbfgs',random_state=20261119)`; same regressions: abiotic-only, source-intensity-only, and abiotic+source-intensity.
- Fixed quantity gate: >=20 training source-qualified positive and >=20 training pseudo-background cells; >=5 each for heldout CO, after WorldClim source nodata exclusions. If any fail, report per-taxon STOP, no threshold adjustment.
- Evaluate heldout **plant GBIF recorded cell vs target-group pseudo-background rank AUC**, plus source-intensity-only and environment increment; report exact-intensity conditional AUC and its comparable-pair fraction as a caveat, not as an independent confirmatory test. **Changing the heldout background population means direct AUC differences from the earlier pilot are descriptive, not paired improvement estimates.**
- Zero raw original coordinates/cell IDs/dataset IDs/taxa×cell scores/raster pixels emitted. All source ZIPs/hashes and full source QC must replay. No forest, bat response, 3D mechanism or M3-vs-M1/N1 AUC is computed. Hold the full 106×17 production ecology until this source-bias diagnostic is examined.
