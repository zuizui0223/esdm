# NeoBat three fixed Colombia plants: cross-dataset source-disjoint refit

Date: 2026-11-19. **Prospectively frozen for the next calculation**, after prior source-matched Colombia 3-species AUC and 106×17 whole-dataset embargo *input feasibility* were inspected. This is post-hoc **exploratory** source-robustness, not independent data or a confirmatory ecology result.

## Exact question

For the **same previously scored Colombia test cells**, how much do the botanical GBIF source-rank AUCs change when fitting the plant model in other countries **without using any source dataset ID that also contributed an original botanical record from Colombia**?

The fixed three original pilot species are `Cecropia obtusifolia`, `Ficus insipida`, `Piper aduncum`. Colombia CO is the only heldout country. Species and country may not be switched based on any AUC. The original 106-plant universe, 17 countries and v1 255-plant resource-SDM estimand remain untouched.

## Fixed data and source disjointness

- Original published GBIF plant ZIP DOI `10.15468/dl.xwc5zf`, 367,988 records, original ZIP SHA-256 `4275ed6b9847fa9fb81a9e353ec1b9de151592f7c369b19f6145129059726c8b`, original source-schema and country×species 25km strict counts replay.
- Original climate BIO1/BIO12 ZIP SHA-256 `00513224583665ec0f2f955a4ec252730c4deb2004cce9e793492a3f26df4dcf` and original WorldClim coarse elevation ZIP SHA `6a9f4e9a37f289d594ed1567b63be344a4dacf247f0b69756e81df031087e3bd` with original 1970–2000 climate baseline. No new GBIF POST.
- In RAM, collect **all nonempty original GBIF `datasetKey` values** from **all Colombia botanical records** in the original 2000–2025 source cohort, regardless of coordinate uncertainty; this exact source-country embargo was fixed and separately verified in the previous source-only audit.
- For **training** from all other original 28 countries, remove each record from those banned GBIF datasets globally. Training positives and pseudo-background are constructed from country/source-`datasetKey` groups that contain at least one focal and other-taxon botanical recorded cell, with positive and background cells unique in EPSG:6933 25km. Keep all original source-known focal cells excluded from background (even if reported by a banned dataset) as a conservative *positive-exclusion mask*, not a predictor or response positive. **Critically recompute the other-plant recorded-taxa intensity predictor for training using only nonembargoed datasets**; do not count a heldout-shared botanical dataset in the training source-intensity covariate.
- Independently embargo **all original Colombia botanical 25km cell IDs** from outcountry training even where cross-border assignment occurs. Training scalar normalization and model fitting only use the now source-disjoint outcountry training set.
- **Heldout CO test records, source matching, valid cell selection, four predictor columns and pseudo-background labels are identical to the previously published dataset-matched three-plant Colombia pilot**, including original full-source other-plant observed taxon count and nodata exclusions. Verify that every fixed sentinel's heldout post-raster positive/background denominator **exactly equals** the old source-matched model, and reproduce old source-matched models/AUCs using the unchanged original implementation in the same runner before interpreting a new score. The new and old AUCs then evaluate the **same test labels/cells**, so descriptive AUC changes are paired; this is **not** new independent validation.
- Keep `StandardScaler` trained outside CO only and `LogisticRegression(C=1.0,class_weight='balanced',max_iter=400,solver='lbfgs',random_state=20261119)`. Compare three fixed specifications: (a) BIO1/BIO12/elevation, (b) `log1p(n_other_plant_taxa_in_cell)` only, (c) both. Identical source-data model settings; no fit on test labels or hyperparameter selection based on score.
- Source/raster quantity stops: training >=20 focal and >=20 other-plant source-matched backgrounds; test >=5 focal and >=5 backgrounds. Preserve all three sentinels with explicit status even if one stops. Do not relax thresholds or substitute plants. Report both raw source-cohort and final raster-valid denominators.
- Output only per-sentinel aggregated row counts, before/after AUCs, within-test paired deltas, exact intensity matched conditional AUC and comparable-pair fractions. **No source datasetKey strings, raw GBIF rows, source occurrence/event IDs, cell IDs, original coordinates, per-cell predictions, raster pixels or masks are to be written**.

## Interpretation

Whole-dataset-key embargo is stronger than a country split, but distinct dataset IDs can still represent the same institution or observer; using original focal positive records as a conservative background-exclusion mask also does not create a completely observation-independent experiment. Source intensity remains mixed with richness and collection effort; no AUC is calibrated plant abundance/fruit supply. No bat M0/M1/M3/N1 biological contrast is estimated. All outcomes will be documented without claiming universal ecology, feeding, or a new independent source.
