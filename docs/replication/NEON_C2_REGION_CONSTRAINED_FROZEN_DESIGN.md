# NEON C2 — Does observed mammal sorting survive a geographically constrained incidence null?

**Frozen before reading the species/sequence response (2026-11-17 JST).** Distinct from Safari14 and CamTrapAsia C1. This is a single, observational, independent-source test, **not** an esdm model fit, E5 detection calibration, causal dispersal test, formal P-value or independent claim about true occupancy.

## Sources and prespecified analysis boundary

Use exactly the three files, **version v1**, Zenodo record [20826511](https://doi.org/10.5281/zenodo.20826511), published June 24, 2026; 13 NEON forest subprojects plus four independent forest plots (USA; one early-growing-season month per subproject; surveys 2015–2022). In the order deployment, sequence, description, published MD5 hashes are `82537cdf0a586fa14c9a8b6afd7be470`, `7531a5b9fb3848ef33e162d5206a6f43`, `be1502427995886ef1c64c10410d1ee2`. Hash-check *before* parsing species responses; record SHA256. No wildlife photographs, fine-grained cameras, deployment IDs or timestamp rows will be included in public result artifacts.

The known deployment schema contains `deployment_id`, `placename`, `longitude`, `latitude`, `start_date`, `end_date`, `subproject_name`. Subproject descriptions are independently published climate/habitat context **only**, not used to choose favorable source categories. Before reading biological rows, a header-only sequence-schema check can validate the necessary fields; a missing essential field terminates C2 without constructing a substitute classifier or choosing an advantageous taxonomic subset. No alternate source versions/records if checks fail.

## Fixed scientific question and estimand

**Does the recorded mammal-species turnover among independent US forest subprojects exceed the expectation from random assignment of the original species-camera incidence, conditional on the regional available species pool and each camera's observed richness?**

A positive result means *recorded project-specific sorting relative to a within-region exchangeable-camera null*; it is not proof of biogeographic source-pool mechanism, habitat selection, barrier crossing, movement, true absence or detection-adjusted occupancy. An explicitly post hoc result from Safari14 motivates this pre-response test but does not set a predicted effect size.

## Eligibility and spatial strata (immutable)

- Only deployment rows with valid date interval of **at least 20 calendar days** (`end_date − start_date >= 20`), coordinates and nonempty unique deployment ID, project and camera place name. Project membership = exact stripped `subproject_name`, camera identity = exact `(subproject_name, placename)`; combine qualifying deployments at the same physical camera into one binary taxon set, while recording duplicate/overlap counts. If conflicting identity for the *same* deployment ID exists, stop. Camera location is median latitude/longitude from its qualifying deployments.
- Two **non-data-tuned** pool strata: **West** if project median longitude is `< -100°`, **East** otherwise. Reject a project if its qualifying cameras cross this longitude boundary. Exact project names do not determine the pool; they are not remapped by favorable biology. A region needs **at least three** projects with **at least 20** eligible cameras each, or it is reported `INSUFFICIENT_REGION_SUPPORT`; do not import another project or change boundary. Both geographic strata must qualify for a two-region success; a failed stratum remains a documented support stop, never a substituted group.
- Sequence rows must provide a valid deployment ID, mammal class (`Mammalia`), and species-rank binomial scientific name (either a scientific-name field or distinct genus and species fields) under header-documented aliases. Exclude blank/non-binomial/uncertain taxa and predeclared domestic species `Homo sapiens`, `Felis catus`, `Canis familiaris`, `Canis lupus familiaris`, `Bos taurus`, `Equus caballus`, `Ovis aries`, `Capra hircus`; exclude nonanimal/person/vehicle/empty and nonmammal records. Each `(camera, binomial)` counts **once**, never number of photos. A scientific binomial found with conflicting mammal versus nonmammal class labels is a response-schema stop; cannot select taxa based on effect direction.
- Per project, sample exactly **10 physical cameras without replacement**, at each of **200 deterministic draws** using `random.Random(20261117)` and stable lexicographically sorted project/camera IDs. Per draw, a species qualifies for a project when detected in **>=2 of its 10 cameras**. Empty or unestimable project pair β is missing, never assigned a favorable value. Retain all eligible project pairs, all draws, both spatial strata, negative comparisons and missing-data reasons.

## Exact randomization and decision rule

- β_sim = `min(b,c)/(a+min(b,c))`, where `a` is shared mammal labels, `b,c` exclusively recorded labels; return missing where denominator zero. For each draw and stratum, compute **median β_sim across all eligible subproject pairs**.
- Primary **within-region fixed-margins null** independently randomizes each region's complete eligible `camera × mammal` binary incidence using two-row curveball trades. Hold fixed the richness of **each physical camera** and the number of positive cameras of **each species within that region**, the project membership and project camera counts, and the original 200 10-camera selections. Perform `30×region camera rows` random pair-trade proposals for initial burn and `15×region camera rows` proposals between each successive null replicate. Seeds West `20261117`, East `20261118`. Exact row/column margins checked after burn, every 50 draws and at end.
- Primary statistic per region: median over all 200 paired draws of `[observed draw pair-median β_sim − null draw pair-median β_sim]`. Record fraction of strictly positive paired differences and descriptive 5–95% range. **Descriptive evidence of regional sorting across both independent geographic strata** requires both strata to have **>=190/200 strictly positive** complete paired draws, with *every* draw having at least three project pairs estimable. If one passes, report split-dependent; if none, no descriptive regional-null excess. These 200 serial curveball matrices are correlated; **do not infer a P-value, 95% CI or independent 200 replicates**.
- Secondary only: median observed β_sim and β_sne by region; all project-pair observed minus randomized median contrasts; exception cases and per-project camera/mammal support. Do not tune prevalence thresholds or study pool membership. Do **not** add an unconstrained all-US null after seeing results to rescue a claim.
