# NeoBat first empirical country-crossfit PLANT suitability pilot (response-opened discovery only)

Date: 2026-11-19. Branch `analysis/neobat-plant-country-crossfit-pilot-20261119`. The original 255-plant v1 M0/M1/M3/N1 benchmark and 84-fold accounting remain frozen and **unestimated**. This is a separate *exploratory v2 plant predictor feasibility test*, not a bat resource-link test.

## Frozen sentinel pilot, before reading plant model outcomes

- Fixed **Colombia (CO) country holdout**, with **no Colombia plant records in any training predictor**.
- Fixed species: `Cecropia obtusifolia`, `Ficus insipida`, `Piper aduncum`. All were included in the previously frozen identical 106-plant taxon universe SHA `41c9fc0128df6d0f3753edf4b82f6b5b36c6975c8d7c644bae4e4fd3e5bdaac6`, prior to this pilot. Do not swap a sentinel if test labels/model results fail.
- Previously minted plant GBIF DOI `10.15468/dl.xwc5zf`, original 367,988-row ZIP SHA `4275ed6b9847fa9fb81a9e353ec1b9de151592f7c369b19f6145129059726c8b`. Re-stream, compare exact original ZIP, replay per-species×country strict 25km source cells against the prior full GBIF QC. Never request a new GBIF download.
- Known geospatial precision <=12,500 m; 2000–2025 source, EPSG:6933 25km cells; unique *observed* cells not individual GBIF rows. No original coordinates, cell IDs, plant records, dataset IDs or source rasters exported.
- Predictors from previously authenticated official WorldClim v2.1 (10 arcminutes) 1970–2000 raster means BIO1 temperature, BIO12 precipitation; WorldClim original elevation ZIP SHA `6a9f4e9a37f289d594ed1567b63be344a4dacf247f0b69756e81df031087e3bd`. All raster sources are opened only after original hash passes. For each 25km EPSG:6933 grid cell sample at the cell centroid; that point can miss valid land near coast, so report all pixel nodata and cell exclusion counts.
- Target-group **plant pseudo-background** uses source records of all **255 original plant species excluding the focal species** in the same country, with focal-recorded cells removed from background. To avoid a trivial observation-effort artifact, *both* positive and pseudo-background cell sets must include >=1 other plant species in the cell. Include `log1p(n_unique_other_plant_species_in_same_cell)` as an exploratory source-effort covariate, not as independent detection probability. Co-observation can be confounded with environmental preference and neither pseudo-background nor missing plant records prove absence.
- Train only in the other **28** fixed source countries (and exclude any 25km cell also represented in CO, even if recorded as foreign-country source). Heldout CO plant occurrences must never enter training features, scaler, hyperparameters or threshold selection. Fit frozen `StandardScaler` (train only), `LogisticRegression(C=1.0,class_weight='balanced',max_iter=400,solver='lbfgs',random_state=20261119)`. Train only if >=20 unique positive and >=20 target-background cells. Test country only if >=5 positives and >=5 pseudo-background cells **after** environmental nodata screening; if not, explicit STOP.
- Evaluate heldout **rank AUC against target-group pseudo-background**, using the same original test cells for (a) environmental BIO1/BIO12/elevation only and (b) environment + observational other-plant source-effort proxy. No tuning or taxon substitutions after observing AUC. Report all denominators, stopped cases, and both score types. Models' relative scores are *not* calibrated presence probabilities.
- This pilot is not a 106×17 production model and does not create the complete same-106-plant crossfitted predictor matrix; no effect of M3 vs M1 or N1 is computed. No forest or bat effort/background enters this pilot. It does not test fruiting, actual resource use, causal mechanisms, or independent external validation.

**Decision:** Only a technical/practical test of plant suitability transfer. Regardless of sign, store results and stops unchanged; any full exploratory M1/M3 benchmark requires *all* 106 plant scores at all bat and background cells, full forest/terrain/effort covariates, and source-blocked bat predictions.
