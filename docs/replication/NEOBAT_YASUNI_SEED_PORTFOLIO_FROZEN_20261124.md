## Fixed calculation
- Stream full `YASUNI_ALL_FINAL.csv`, require the expected long columns `Day_Year_Y,variable,value`. Match to fixed plants only by exact author code + exact current binomial, no shared-environmental plant imputation. All observed numeric zero records remain zeros; missing code×timepoint pairs and explicit NA remain **missing**. Reject duplicate code×time records, negative/nonfinite seed counts, corrupt sources, contradictory name/code mapping.
- Per fixed primary bat: source records restricted to `Frugivory`, `Frugivore`, `CurrentBatSpecies` and `CurrentPlantSpecies` exact names. Retain source-linked plants represented in the final Yasuní records. Evaluate only for **>=3 species and >=60 jointly observed timepoints**; all other 26 entries carry explicit unknown/not eligible with null ratios. Timepoint = source `Day_Year_Y`, not reconstituted calendar date or presumed 14-day regular intervals.
- As in CC1: transform `log1p(seed count)`, normalize each plant by mean transformed count across shared timepoints, average species equally per timepoint, and compute across-time sample CV. Use **499 independently circularly shifted within-species sequences**, RNG seed `20261124`, original frozen Python `random.Random` algorithm or fully documented deterministic implementation. A ratio observed CV / median(null CV) below one is descriptively more compensatory than a free-shift null, above one more synchronous. The free-shift null removes shared seasonality, so it cannot identify bat-specific mechanisms or control climatic seasonality.
- **Second comparison frozen before values here** (post-hoc in CC1): among *all* exactly matched fixed-plant Yasuní species in the actual final file, enumerate all `C(n,k)` plant sets of the same size `k` as each eligible bat candidate. Compare the unchanged observed portfolio CV to the median CV of the exhaustive same-size set distribution, report inclusive fraction with CV <= observed. This is a descriptive rank, **not a p-value**, and retains all 26 candidates and duplicate source-linked plant-set groups; no choice based on score. If n too small for k or a complete-case set has fewer than 60 points or zero mean, keep explicit non-estimable and do not substitute or exclude taxa to improve result.
- Separately list the exact species shared with CC1, if any, but do **not** average site-level ratios or claim the same bats consumed them at both locations. Different studies and species composition prohibit direct prediction performance transfer.
- Preserve original author source Git blobs and SHA256 in reproducible aggregate receipt, without uploading original raw 14.6 MB table, trap coordinates or individual bat locations.

## Inferential boundary
This is a *second original botanical field dataset* from a different Amazonian site, but the two sites share the same published Pak et al. study, preprocessing design and likely phenology source network. They are **not independent studies** and the same NeoBat literature catalog is reused across both. No locally measured Yasuní/CC1 bat diet, no ripe accessible fruit biomass, no site-year bat abundances/activity, no M3–M1 or N1 effect estimates. The published paper already reports site-level whole-community synchrony and localized temporal compensation; these mechanisms are not novel claims by themselves. New scope only tests the **fixed original source-linked plant-subset** and whether its behavior differs descriptively from same-size plant sets.
