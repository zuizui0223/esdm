Date frozen: 2026-09-27

## Trigger

N1 is the known-truth world in which the residual field is exchangeable rather than
geographically coherent. The original gate required only:

```text
BC - BX on H1 = null
```

That is insufficient as a negative control because the same null can occur if the
exchangeable heterogeneity is too weak to be predictively detectable at all.

No MAP1 confirmatory outcome, shard, fit, or held-out gain has been opened.

## Frozen detectability firewall

N1 now requires both:

```text
BX - B0 on H1 = positive-qualified
BC - BX on H1 = null-qualified
```

Thus N1 counts only when generic latent heterogeneity is demonstrably learnable but
geographic coherence adds no extra information.

## Execution-cardinality amendment

The added B0 fit in N1 changes the frozen complete execution from:

- 48 shards / 128 fits

to:

- **48 shards / 144 fits**.

All three worlds therefore fit B0, BX, and BC exactly once per replicate.
