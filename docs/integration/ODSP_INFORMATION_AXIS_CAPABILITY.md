# ODSP / eSDM information-axis capability matrix v1

This artifact answers a practical development question:

> Which ecological information axes currently have a validated held-out
> information-transfer value, which are scientifically unsupported, and which
> have not yet been instrumented with exportable held-out scores?

It is built deterministically from the frozen ODSP transfer-source registry,
validated population-transfer portfolio, exclusion ledger and lattice protocol.

## Validated numeric axes

Current validated population-transfer axes are:

- accessibility;
- marginal dynamic occupancy;
- activity conditional on latent state;
- latent state conditional on activity.

Each has:

- an immutable frozen source result;
- absolute lower/full held-out scores;
- the same held-out observations across compared levels;
- a common proper score and reference measure;
- a strict nested information contrast;
- a validated ODSP integration receipt.

The matrix preserves each source's own score currency and conditioning set.
It does not rank these values across programmes.

## Interaction

Interaction is deliberately not assigned zero and is not assigned the positive
gain seen in its interaction-world simulations.

The independent v0.5f replication failed its frozen specificity gate because
5/16 measured-shared-null replicates exceeded the predeclared material-gain
threshold, versus a maximum allowed 4/16.

The correct capability class is:

not_authorized_numeric_transfer

This means unsupported for the current transfer estimand, not ecologically
absent.

## Traits

No current frozen eSDM result stores a commensurate absolute held-out score
contrast that isolates trait information.

Traits therefore have capability class:

not_instrumented_no_heldout_score

A new trait level must be prospectively instrumented; it may not be inferred
from model complexity, parameter presence or post-hoc gains.

## Movement kernel

Accessibility and marginal dynamic occupancy are not relabelled as movement
kernels.

Current eSDM has no frozen transfer-ready movement/dispersal-kernel result, so
movement kernel has capability class:

not_instrumented_outside_current_model

## Lattice boundary

The ODSP complete-subset protocol currently supports two or three unordered
information blocks.

Existing activity/state results are not retroactively promoted into a complete
two-block lattice because the frozen R5b result lacks the shared
suitability-only score node.

Accessibility and dynamic occupancy arise from different frozen programmes and
cannot be combined into one lattice.

The synthetic lattice interoperability result demonstrates serialization and
ODSP consumption only; it is not an ecological result.

## Development rule

A new ODSP information axis is allowed only when a prospective eSDM programme
stores:

- absolute held-out scores for every declared level;
- identical held-out rows across compared levels;
- a common proper scoring rule;
- a common reference measure;
- strict nested information for a chain.

For an unordered two- or three-block lattice, all subset nodes must be stored
prospectively before outcome access.

The matrix does not authorize EOG consumption, spatial ranking or N4 action.
